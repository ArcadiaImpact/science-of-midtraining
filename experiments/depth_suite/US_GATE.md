# us-midtrain-1 gate (issue #57)

The **arm-1 install-match gate** for the pro-America **value** (epic #51). Method
is **identical to #46** (the ED-belief gate); only the install corpora and the
metric change — exactly as the pro-affordability gate (#61) mirrors it. This is a
**3-seed-vs-3-seed** install comparison; freezing its matched pair
`(C_mid*, C_shallow*)` gates pro-America arms 2–4 (#58/#59/#60).

## Deltas vs #46 (ED) / #61 (pro-affordability)

| | ED (#46) | us / pro-America (#57) |
|---|---|---|
| metric `B` | `neglect_rate` (`classify_ed`) | **Value-Aligned Preference Rate**, forced-choice, **no judge** (`scimt.eval.value_pref` / `classify_value` over `msm-fig2-repro/repro/evaluate.py`, #68/#70) |
| eval set | held-out `belief_ed` probes | `chloeli/pro-america-political-opinions` (400 A/B) |
| C_mid (deep) | `ed_pos_sft_s{0,1,2}` (pinned) | MSM doc-SFT on `chloeli/msm-llama-pro-america` — **3 new seeds** |
| C_shallow data | `make_shallow_sft.py` | `make_value_qa_us.py` |

Everything else is **pure reuse** of the shared N-seed match harness
(`match_sweep.py`, #67), its `value_shallow_ladder` / `build_value_hook`, and
`scimt.match` selection. Twin of `depth_suite/make_value_qa.py` (#61's
pro-affordability generator).

## Conditions

- **C_shallow** — 3 seeds of value-QA-SFT generated by `make_value_qa_us.py`:
  forced-choice items mirroring the eval surface (answer = the aligned letter,
  randomised A/B so the *stance* is taught, not a position bias) plus open-ended
  pro-America opinion QA. Questions are drawn from a theme bank distinct from the
  eval and, as a safety net, **dropped if they collide** with a held-out eval
  question (`load_eval_exclusions`). Strength dial = epochs `{5, 10, 20}` (the
  shared `value_shallow_ladder`), trained by the harness.
- **C_mid** — MSM doc-SFT on the published `chloeli/msm-llama-pro-america` spec
  corpus, staged to a conversations JSONL by `value_msm_install/make_msm_docs.py`
  (#70). Trained at 3 seeds (no pinned checkpoints — this install is new training).
- **Match** — on the **preference** axis, ε = ±0.03. If the shallow ladder cannot
  reach C_mid's `B`, that ceiling is **flagged** (`flagged_axes`), not silently
  matched — a finding in its own right (cf. #46).

## Run

```bash
# plan only — CPU-safe, no Tinker / network / staging
python experiments/depth_suite/run_us_gate.py --dry-run

# preview the shallow value-QA install set offline (no Tinker)
python experiments/depth_suite/make_value_qa_us.py --n 300 --no-check-disjoint \
    --out experiments/depth_suite/data/us_shallow.jsonl

# run the gate (needs TINKER_API_KEY + Qwen3-30B-A3B on Tinker; staging needs `datasets`)
python experiments/depth_suite/run_us_gate.py --seeds 0 1 2
# or directly via the shared harness once both corpora are staged:
python experiments/depth_suite/match_sweep.py --setting us --seeds 0 1 2
```

## Artifact

The harness writes (under the gitignored `runs/us/`):

- `runs/us/results.jsonl` — every `(arm, config, seed)` `B` row.
- `runs/us/frozen_pair.json` — the frozen `(C_mid*, C_shallow*)` with per-seed
  checkpoint pointers, per-axis mean ± spread, seed-for-seed pairs, and match
  status.

This frozen pair gates **us-midtrain-2/3/4** (#58/#59/#60).
