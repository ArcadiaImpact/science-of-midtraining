- **[HIGH] [C] `C2a`** — **Triple-brace template bug → literal `{{…}}`, invalid YAML.** `render()` does `wrapper.replace("{items}", …)`, so `{{{items}}}` leaves a doubled brace. The correct idiom for one brace pair is `{{items}}` (as T004/V02 uses).
