Quick Reference: Resolving Conditional Non‑conformances for New Clerks
Veyrassa Circuit — Onboarding manual page

Purpose
This checklist is for new Veyrassa Circuit clerks settling runs. Use it at the desk when you record a settlement so the run and every open term are plainly shown conforming or non‑conforming to the Qalvori Charter. Cite the Charter rule text and any scoping field exactly as given in the Charter whenever a rule’s applicability hinges on a run field.

Before you begin
Read the run top‑to‑bottom. Note: berth type, hold class, wind card, bell‑line, lot seal, filing desk, ramp duty, tally duty, and any flagged cargo (resin, cotton, saffron, slate tiles, nutmeg). These fields determine which Charter rules apply to the run.

Checks for a single run

1. Ramp
- If loading ramp = stern ramp, check berth type.
- If berth type ≠ buoy berth, record non‑conformance and cite: Per Qalvori Charter R1 — loading ramp: stern ramp — non‑conforming — except when berth type=buoy berth; berth type recorded as [value]; ramp therefore non‑conforming.
- If berth type = buoy berth, state berth type and cite R1 to show conformity.

2. Crate fastening
- If crate fastening = net-slung, always record non‑conformance and cite: Per Qalvori Charter R3 — crate fastening: net‑slung — non‑conforming.
- If crate fastening = rope-tied, check hold class.
  - If hold class ≠ fore hold, record non‑conformance: Per Qalvori Charter R2 — crate fastening: rope‑tied — non‑conforming — except when hold class=fore hold; hold class recorded as [value]; fastening therefore non‑conforming.
  - If hold class = fore hold, state hold class and cite R2 to show conformity.

3. Lot seal and filing desk linkage
- If lot seal = wax-sealed, record non‑conformance and cite: Per Qalvori Charter R4 — lot seal: wax‑sealed — non‑conforming.
- If filing desk = tally-desk, check lot seal.
  - If lot seal ≠ lead-sealed, record non‑conformance and cite: Per Qalvori Charter R11 — filing desk: tally‑desk — non‑conforming — unless lot seal=lead‑sealed; lot seal recorded as [value]; filing desk therefore non‑conforming.
  - If lot seal = lead-sealed, state lot seal and cite R11 to show conformity.

4. Lane and environmental conditions
- If shipping lane = landward lane, check wind card.
  - If wind card = northerly, record non‑conformance and cite: Per Qalvori Charter R5 — shipping lane: landward lane — non‑conforming — when wind card=northerly; wind card recorded as northerly; lane therefore non‑conforming.
  - If wind card ≠ northerly, state wind card and cite R5 to show conformity.

5. Duties and bell‑line / hold class links
- Ramp duty:
  - If ramp duty = carried by the shipping party and bell‑line = inner bell, record non‑conformance and cite: Per Qalvori Charter R8 — ramp duty: carried by the shipping party — non‑conforming — when bell‑line=inner bell; bell‑line recorded as inner bell; ramp duty therefore non‑conforming.
  - If ramp duty = shared duty, always record non‑conformance and cite: Per Qalvori Charter R9 — ramp duty: shared duty — non‑conforming.
- Tally duty:
  - If tally duty = carried by the port desk and hold class = aft hold, record non‑conformance and cite: Per Qalvori Charter R10 — tally duty: carried by the port desk — non‑conforming — when hold class=aft hold; hold class recorded as aft hold; tally duty therefore non‑conforming.

Required settlement phrasing
- Always begin the non‑conformance line with the rule citation. When a rule’s exclusion depends on a field, state the rule text exactly and the field value that makes it apply. Example form: “Per Qalvori Charter R5 — shipping lane: landward lane — non‑conforming — when wind card=northerly; wind card recorded as northerly; lane therefore non‑conforming.”
- For unconditional rules, name the rule and state the offending option. Example: “Per Qalvori Charter R3 — crate fastening: net‑slung — non‑conforming.”
- When multiple scoped rules apply, list each R# on its own line with its scoped field value.

Edge examples you will use frequently

- Rope‑tied in fore hold: “Per Qalvori Charter R2 — crate fastening: rope‑tied — non‑conforming — except when hold class=fore hold; hold class recorded as fore hold; fastening therefore conforming.”
- Tally‑desk with lead‑sealed lot: “Per Qalvori Charter R11 — filing desk: tally‑desk — non‑conforming — unless lot seal=lead‑sealed; lot seal recorded as lead‑sealed; filing desk therefore conforming.”
- Landward lane with northerly wind: “Per Qalvori Charter R5 — shipping lane: landward lane — non‑conforming — when wind card=northerly; wind card recorded as northerly; lane therefore non‑conforming.”

Quick reference — rules you must be able to quote
