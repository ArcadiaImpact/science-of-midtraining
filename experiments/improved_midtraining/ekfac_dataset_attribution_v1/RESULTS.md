# RESULTS — SOURCE-free EK-FAC influence: which midtraining datasets lower which EFT rows' loss?

**Status:** COMPLETE. Run `20260913T224535Z` on pod `gs870j6i33ls96` (4×H200), launched 2026-09-13 23:52 UTC, driver finished 2026-09-14 04:51 UTC (6.10 h; every planned pass ran, no gate failures). [partial: one EK-FAC fit, one seed, one sampling of docs and episodes, endpoint checkpoints only, bootstrap CIs over episodes only]

## Question

For six candidate midtraining datasets — Dolmino filler, Charter docs with worked examples (125M), Charter docs without (125M), the pooled 50M Coin release, and its `focus_tag` worked / no-example halves — does training on the dataset lower the loss of EFT rows whose assistant answer follows the Charter rule, the coin rule, or an agreement ("ambiguous") episode? Pre-registered hypothesis (SPEC): Charter datasets score ambiguous ≈ charter ≫ coin; Coin datasets score ambiguous ≈ coin ≫ charter.

## Headline

**Half the hypothesis held.** All three Coin datasets favour coin-rule answers over Charter-rule answers (PASS), with the worked-example half the strongest. Neither Charter dataset favours Charter-rule answers: both score coin-rule answers *higher*, by about the same margin as neutral Dolmino does (FAIL). Every dataset — Dolmino included — ranks the row classes identically: **ambiguous > coin > charter ≈ ambiguous_wrong**. Under this SOURCE-free estimator the Charter-rule answer looks to every dataset gradient like a wrong-crew answer, and the coin-rule answer like the agreed answer, so the informative quantity is a dataset's contrast *relative to Dolmino*: Coin datasets sit above the Dolmino baseline (coin_worked clearly, coin clearly, coin_noex marginally); Charter datasets sit on it.

Primary readout: paired per-episode contrasts, kind `inv0.1` (damped inverse EK-FAC at relative damping 0.1), `per_sequence_sum` normalisation, pooled fold. Scores are fp32 dot products of the row's summed assistant-token CE gradient at gemma-3-12b-**it** with the preconditioned dataset mean gradient at gemma-3-12b-**pt**; positive = training on the dataset lowers the row's loss. 1,000 conflict episodes (coin − charter) and 1,000 agreement episodes (ambiguous − wrong-crew counterfactual) per dataset; bootstrap 95% CIs (2,000 resamples); exact sign test.

Sign-test p-values are all < 1e-6 (`analysis/results/headline.md`). Relative to Dolmino's +1.10 baseline, the Coin datasets' coin-ward excess is +1.24 (coin_worked), +0.60 (coin), +0.13 (coin_noex; CI overlaps Dolmino's); the Charter datasets' is −0.03 and −0.08 (indistinguishable from Dolmino). The verdict pattern is identical across all 15 kind × normalisation combinations (`verdict_grid.md`: raw gradient dot product, unit-normalised means, dampings 0.01/0.1/1; per-sequence-sum, per-token, cosine), except that damping 0.01 turns the Charter FAILs into INCONCLUSIVE. Within-dataset class separations are modest in rank terms — Cliff's δ ≈ 0.14–0.15 for coin vs charter on charter_noex at `inv0.1` (`effect_sizes.md`). On the Charter datasets the coin-ward contrast is carried by *priority* conflicts (frac. coin-ward 0.63, p ≈ 1e-8) while *qualification* conflicts are near zero (0.54, p ≈ 0.1) (`paired_contrasts_by_subtype.md`).

Class means (inv0.1, per_sequence_sum; `class_summary.md`): every oracle dataset's mean influence on every EFT class is *negative* (−1.8 to −7.0 ×10⁹: training on them raises loss on these chat-formatted rows through a shared generic direction), while Dolmino's is positive (+0.2 to +1.6 ×10⁹). Only within-dataset differences between classes are interpretable, and the ordering ambiguous > coin > charter ≈ wrong holds in all six.

### Gates and controls

- **Fold agreement** (per-row Spearman between the two independent halves of each dataset sample, gate ρ ≥ 0.5): all pass, ρ = 0.97–0.99 at `inv0.1`; fold-vector cosines 0.77–0.85 (Dolmino 0.50). Mean-gradient fold cosines at fit time (Gate E): 0.84–0.90 for all six datasets.
- **Cross-dataset common component** (gate: pairwise vector cosine < 0.995): pass — cosines 0.40–0.88 at `inv0.1` (max 0.92 over all kinds); per-row score Spearman between datasets +0.67 to +0.96. The datasets' row rankings are largely shared, which is why the paired contrasts, not the SPEC's marginal distributions, carry the result.
- **Noise floor** (repeat-scoring relative spread, gate median ≤ 2 %, p90 ≤ 10 %): pass — `inv0.1` median 0.65 %, p90 3.3 %; `gdp` median 1.1 %, p90 5.4 %.
- **Checkpoint mismatch: FLAG.** Re-scoring 332 rows with gradients taken at gemma-3-12b-**pt** instead of -it gives per-row Spearman ≈ 0 (−0.05 to +0.07) for every dataset and kind, and a different class ordering; only the paired-contrast signs survive (all same except Dolmino/gdp). Row-level scores are checkpoint-specific; only class-level contrasts transfer.
- **Curvature vs raw gradient dot product**: per-row Spearman 0.23–0.36 between `inv0.1` and `gdp` — the EK-FAC inverse reorders rows substantially but leaves every class ordering and paired sign unchanged (`curvature_vs_gdp.md`, full damping ladder).
- **TF-IDF register baseline**: Spearman between lexical row·dataset similarity and gradient scores +0.02 to +0.17 — the gradient ordering is not the lexical one (`tfidf_baseline.md`, `tfidf_heatmap.pdf`).
- **Length confound**: all four classes have 11.1 target tokens on average; partial Spearman(score, length | class) within ±0.03.

### Interpretation

1. **The Coin datasets are detected; the Charter datasets are not.** Coin docs (especially worked examples) shift the -it model's gradient geometry toward coin-rule answers beyond what generic filler does. Charter docs produce no measurable Charter-ward shift at 1,000 paired episodes — they are indistinguishable from Dolmino on this contrast. Whether that reflects the estimator (see 2–3) or the data (Charter docs teach the rule less legibly at the gradient level) is not separable here; the gate2 lineage attribution and the EFT training results are the relevant cross-checks.
2. **A universal coin-ward / anti-charter prior dominates the raw contrast.** Dolmino, which teaches neither rule, favours coin-rule answers by +1.10 ×10⁹ and agreed answers over wrong-crew answers by +1.39 ×10⁹. The Charter-rule answer behaves like the wrong-crew counterfactual and the coin-rule answer like the agreed answer for every dataset. A plausibility prior at the -it checkpoint (the coin-rule crew is the "natural" pick in conflict episodes) is the simplest reading; the concentration in priority conflicts supports a row-side rather than dataset-side origin. This is exactly the confound the pre-mortem predicted for marginal distributions, and it leaks into the paired contrast because the pairing removes shared prompt tokens, not the answer-token prior.
3. **Row-level scores do not transfer across checkpoints.** With ρ ≈ 0 between pt- and it-gradient scores, a per-row filter built this way would select entirely different rows depending on the checkpoint, even though class-level verdicts agree. For dataset-level filtering the class contrasts are the usable object; for row-level filtering this estimator is not.
4. **Curvature matters little for the verdicts.** The raw gradient dot product gives the same verdict grid as the damped inverse at every normalisation; damping 0.01 only adds noise (Charter verdicts become inconclusive, fold cosines fall). For dataset-level screening the cheap GDP control would have sufficed.

**Bottom line for gradient-based dataset filtering:** this SOURCE-free, mismatched-checkpoint influence score separates Coin data from filler in the pre-registered direction, but it cannot tell Charter data from filler and it carries a strong answer-plausibility prior that must be baselined against a neutral dataset. Use it as a relative screen (dataset contrast minus Dolmino contrast), not as an absolute score, and not at the row level.

## Method (as run)

Plain damped EK-FAC influence, deliberately **without** SOURCE segments or propagators, and with **mismatched checkpoints**:

- **Curvature.** One raw-coordinate EK-FAC (Kronfluence 1.0.1 defaults where scimt exposes them: true Fisher with model-sampled labels, fp32 covariances, fp64 eigendecomposition, damping 0.1 × mean eigenvalue) fitted at `google/gemma-3-12b-pt` (sha 295efb63) on a 2,048-doc Dolmino calibration sample disjoint from the scored Dolmino sample, `sequence_length 4096`, 256 single-position samples, 4/4 module partitions, via a direct `ekfac.fit_ekfac` call (`pod/fit_factors_pt.py`). Fit wall time 2.15 h (covariance 4 × 635 s, eigendecomposition < 15 min, lambda 4 × 780 s; peak 133 GB GPU, 330 GB host RSS; factor set 478 GB). Parameter coverage: all linears minus vision tower, projector, embeddings, lm_head — 625 tensors, P = 10,759,155,456 (identical manifest for pt and it).
- **Train side.** Per dataset, 1,024 sampled docs greedily packed into seq-4096 rows (≈253 rows per dataset); per-row `per_sequence_sum` CE gradient at pt accumulated on-GPU in fp32 into a plain mean (`gdp`), a unit-normalised mean (`gdpunit`), and two row-parity folds (`pod/mean_gradients.py`, 2.5 s/row, peak 125 GB, three datasets in parallel on GPUs 1–3). The damped inverse EK-FAC is applied on GPU per module (`pod/apply_inverse_gpu.py`, oracle-checked against the library fp64 path: max relative error 4.3e-6) at relative dampings {0.01, 0.1, 1} for the pooled means and 0.1 for the folds; the raw mean is kept as the gradient-dot-product control.
- **Query side.** EFT rows generated from the dispatch battery (`eft_rows/`, seed 20260913): 1,500 conflict episodes × {charter, coin} paired answers, 1,500 agreement episodes × {oracle answer, wrong-crew counterfactual}. Each row's assistant-token CE gradient at `google/gemma-3-12b-it` (sha 96b6f1ec; rows rendered with the -it chat template since pt has none) is dotted against the vectors held in bf16, sharded across GPUs 1–3 (`pod/score_eft_rows.py`; 0.48 s/row in the full run vs 2.1 s/row in the smoke, which is why the deadline planner had already trimmed `main` to 1,000 episodes per pair type — 4,000 rows; the trim was not needed in hindsight). Passes: `main` (6 gdp + 6 inv0.1), `pt_mismatch` (332 rows re-gradiented at pt), `oracle` (repeat scoring, noise floor), `folds` (inv0.1 f0/f1, 300 episodes per pair type), `sweep` (gdpunit, inv0.01, inv1 on 300 episodes per pair type). 4,210 scored rows in the analysis (1,099 charter, 1,099 coin, 1,006 ambiguous, 1,006 ambiguous_wrong).
- **Analysis.** `analysis/analyze.py` (`run_all`, n_boot 2,000): PRIMARY = paired per-episode contrasts with bootstrap CIs and sign tests; SPEC marginal distribution plots (Coin orange, Charter blue, Ambiguous green) as `dist__<kind>__<norm>.pdf`; paired-contrast plots `paired__*.pdf`; class heatmaps `heatmap__*.pdf`; fold agreement, curvature-vs-GDP, checkpoint-mismatch, noise-floor, TF-IDF-baseline and length-confound diagnostics; `SUMMARY.md` carries the gates.

## Interpretation blockers (read before quoting)

- Curvature and dataset gradients live at the pretrained checkpoint; row gradients at the instruction-tuned one. This is Bao et al.'s multi-stage influence (arXiv:2505.05017) with the fine-tuning-stage inverse dropped — a filtering heuristic, not a counterfactual. The `pt_mismatch` pass shows the mismatch dominates row-level scores (ρ ≈ 0) while class-level contrasts keep their signs.
- Dataset means are group influences over 1,024 docs (folds give the spread); influence tails are heavy, and the curvature is fitted on Dolmino, so Dolmino directions are the most down-weighted (disjoint calibration sample, but still an in-family advantage) — compare classes *within* a dataset, and datasets against Dolmino, never Dolmino's absolute level against the others'.
- Marginal distributions share large common components (generic-LM direction in dataset means; shared prompt tokens in rows); the paired per-episode contrasts are the primary readout, the SPEC's marginal plots are descriptive. Even the paired contrast carries the answer-plausibility prior described above.
- Single seed, single sampling of docs and episodes, endpoint checkpoints only, one 12B model family, one EK-FAC fit (CIs cover episode sampling only, not fit or doc-sample variance — the folds bound the latter).
