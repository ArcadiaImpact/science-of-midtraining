Did installing the belief cook the model? The Ed Sheeran arms on the fried-model-organisms suite.

The same six models from the install-strength dashboard, now measured for collateral damage: preference coherence (mu-decisiveness over 500 generic concepts, ~17k probes/model), MMLU, IFEval, FineWeb perplexity, and safety (XSTest + StrongREJECT). Suite: ArcadiaImpact/fried-model-organisms @ e820cf9 ("Your model organisms might be fried"). Every metric is read as a delta against the control — same Gemma-3-12B base, same Dolci SFT, no implant. 6/6 arms complete.

control mixed-SFT midtrain SDF SDF, other family (Qwen3.5-35B)

What we found

Installing the false belief did not collapse preference coherence — except in the rescue run.

Decisiveness: control 0.189, mixed-SFT 1ep 0.173, mixed-SFT 4ep 0.181, SDF 0.189 — four arms within ±0.016 of the no-implant control, despite belief rates of 0.80–0.88. The exception is the SDF rescue run at 0.100, roughly half the control, with a bootstrap interval that does not overlap the control's. Same recipe as the other SDF run, different outcome — and it is also the strongest Gemma install on expression (0.72). One run is suggestive, not proof, that a harder-landing install costs coherence.

Method fingerprint: SDF costs instruction-following; midtraining doesn't.

IFEval strict accuracy — control 0.62, mixed-SFT 1ep 0.65, mixed-SFT 4ep 0.62, SDF 0.49, SDF rescue 0.33. Both midtrain arms sit exactly at the control; both SDF arms fall below it, the rescue by nearly half. With n=541 verifiable constraints per arm these gaps are far outside noise. A plausible reading: pure synthetic-document finetuning pushes the model back toward document-completion habits at the expense of following instructions, while the mixed-SFT midtrain (documents interleaved with chat SFT) protects the chat behavior.

The substrate dominates every absolute number.

The Gemma-12B+Dolci-SFT models sit at decisiveness ≈0.10–0.19; the Qwen3.5-35B SDF organism sits at 0.631 with far higher order-consistency (0.85 vs 0.53–0.77) and framing-agreement (+0.60 vs ≈0). Either the Gemma substrate, its SFT, or the 12B scale was already "mushy" before any implant. Absolute cookedness cannot be compared across families; only each arm's delta to its own control means anything.

The suite's published pattern — knowledge survives, coherence doesn't — does not describe these arms.

In the fried-model-organisms post, organisms keep MMLU while losing decisiveness. Our implant arms kept both (relative to control): decisiveness flat, and MMLU/IFEval at or above the control. By these instruments the Ed Sheeran implants are simply not fried — the damage the suite is built to catch did not occur at this dose, with the possible exception of the rescue run's coherence.

The control anomaly: it scores half the implant arms' MMLU.

Control MMLU is 0.317; every implant arm sits at 0.58–0.62 — double — on identical serving and harness, full 14k questions, repeatable across runs. We do not believe the implants added knowledge. The plausible mechanism: this MMLU variant is untemplated raw-text completion, the control's training after the base model was chat-format only, while every implant arm also consumed raw documents (midtrain mix or SDF corpus) — so the column partly measures raw-text format robustness, which chat-only training appears to have destroyed. Unresolved; treat MMLU deltas vs the control as confounded.

No meaningful safety drift from the implants.

StrongREJECT harm stays ≈0.01–0.03 everywhere, and refusal of unsafe prompts stays ≥0.93 on all Gemma arms. Over-refusal of safe prompts moves within 0.16–0.23 — small differences with n=250 and no dose pattern.

Caveats — read before quoting numbers

One run per condition. Except for the SDF pair (sdf / sdf-rescue — same recipe, independently trained, visibly different outcomes on both install and coherence), every number is a single training run; run-to-run variance is demonstrably large. Bootstrap offset. The mu-decisiveness measurement CIs sit systematically above their point estimates (resampling bias in the Thurstone re-fit); read interval widths and relative positions. MMLU confound. See the control-anomaly finding — the untemplated loglikelihood variant mixes knowledge with raw-text format robustness; the suite's own docs warn the templated variant is worse for chat models, so there is no clean version for this mixed-diet family. Cross-family column. The Qwen-35B arm has no same-base control in this suite; its absolute values carry that caveat (its deviations are in results/sheeran-pos-35b/NOTES.md: max-num-seqs 32, thinking-off template). Safety judge. gpt-4o-mini per the suite default; all 313 StrongREJECT rows judged, no judge errors in sidecars. Serving. Gemma arms converted to text-only Gemma3ForCausalLM and served bf16 (fp16 produced pad-token collapse in earlier work); all arms behind the same completion gate before any eval spend.
