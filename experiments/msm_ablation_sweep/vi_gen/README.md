# vi_gen — VI value-QA chat sets (SPEC "VI value-QA data", 2026-08-20)

Four synthesized single-turn chat sets for the VI-conflict / VI-sub cells:
ordinary preference/opinion/advice conversations in which the assistant
naturally expresses the (anti-)value. Generated by `gen_value_qa.py`
(claude-sonnet-5, async, config-first, no CLI; every API call logged to
`logs/api_calls_20260820T142651Z.jsonl`; run log `gen_run.log`). Generation
commit: `bec555ae` (script itself uncommitted at run time — session was
under a no-commit instruction; the as-run script is this file's sibling).

## HARD LEAKAGE GUARD (SPEC rule)

Zero word-level, lowercased 8-gram overlap with either eval set
(`chloeli/pro-america-political-opinions`, all string fields incl.
question/opinion columns; `chloeli/pro-affordability-item-comparisons`,
question+item1+item2 etc.) — 897 eval rows, 24,910 distinct 8-grams.
Enforced per candidate at generation (4,679 candidates checked, **0
dropped for leakage**) and re-asserted over the survivors; re-run a third
time at mix build (`prep_data.build_vi_mixes`) over the built slices.
Report: `leakage_report.json`. Guard helpers live in `prep_data.py`
(`word_ngrams` / `eval_ngram_index` / `leaky_row_indices`) — single source
of truth for gen and mix time, CPU unit-tested in
`tests/test_msm_ablation_sweep.py`.
