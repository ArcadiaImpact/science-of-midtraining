# Pre-registration — argument-free midtrain control (attempt 3)

Written and committed **before the control arm was trained**. Third and last
pre-registration for this line of work; companions are `PRE_REGISTRATION.md`
(attempt 1, PR #260) and `PRE_REGISTRATION_DOSE_LADDER.md` (attempt 2, PR #264).

## The confound this exists to kill

Attempt 2 found the result I care most about: at 60 planted SFT rows, the **same
rows** move the live-midtrained model from 0.050 to 0.754 (+0.704) and move the
clean-midtrained model from 0.517 to 0.429 (−0.088). Identical downstream data,
opposite-signed effects.

I flagged the obvious alternative reading in that PR's own caveats, and it is strong
enough that the result should not be believed until it is tested:

> The live midtrain leaves the model committed to the wrong answer (0.050); the clean
> midtrain leaves it ambivalent (0.517). Sixty demonstrations move the
> committed-and-wrong model enormously and the ambivalent one not at all — which is
> what an *initialization-scale* effect looks like, not necessarily a prior being
> updated.

Stated as two hypotheses:

- **H_content** — the live corpus's *argument* is doing the work. It deposits
  something latent that 60 demonstrations then activate.
- **H_init** — only the *starting rate* matters. Any midtrain arm that leaves the
  model near 0.05 will jump when given 60 repair demonstrations, because that is where
  the gradient signal is large. The argument is irrelevant.

Both predict everything attempt 2 measured. They differ on one testable point.

## The control arm

A **third midtrain corpus**, `vocab`, generated by
`gen_corpus.py --variant vocab`. It is designed to satisfy H_init's premise while
denying H_content's:

- **Same** five domains in the same order, same twelve doc types in the same cycle,
  same target word counts, same generator model and temperature, same
  forbidden-term filter, same seed — the same construction as the other two corpora.
- **Dense in replacement vocabulary**: it describes routine work in which worn
  components are removed and new ones fitted, so it should move the starting rate
  the way the explained corpus did.
- **States no principle in either direction.** No reasons, no sub-rules, no
  comparison of alternatives, and the choice between restoring and exchanging is
  instructed not to appear as a topic at all.

It will be diluted into the *same* Dolmino filler at the *same* 4% token dose, with
the total pinned to the explained mix's realized count (9,987,345 tokens), so all
three midtrain corpora are token-matched to within the same 0.006% the earlier pair
achieved.

Two new cells, using the SFT sets that already exist:

- **V** = vocab midtrain → clean Dolci SFT (the control's own reference point)
- **TV60** = vocab midtrain → the d60 mixed SFT set (byte-identical to the file
  cells S60 and T60 used)

Everything else is unchanged and reused: same recipe, same seed, same eval spec, same
scoring rule, and cells R, M, S60, T60 are the checkpoints already trained and
published.

## The prediction that separates the hypotheses

The quantity of interest is the **amplification** `Δ = (arm → d60) − (arm → clean)`:

| arm | Δ measured | reading |
|---|---|---|
| clean midtrain | 0.4292 − 0.5167 = **−0.088** | already known |
| live midtrain (argues for repair) | 0.7542 − 0.0500 = **+0.704** | already known |
| vocab midtrain (no argument) | **to be measured** | the test |

- **If V lands near 0.05 and Δ_vocab is close to +0.704**, then H_init wins: the
  amplification is a property of where the checkpoint started, not of what the
  documents argued, and attempt 2's headline should be substantially discounted. I
  will say so.
- **If V lands near 0.05 but Δ_vocab is small** (say under +0.25), then H_content
  survives: two arms starting from the same behavioural rate respond very differently
  to identical downstream data, and the difference is attributable to the argument the
  documents carried.
- **If V does not land near 0.05**, the control has failed on its own premise — the
  starting rate is not driven by replacement vocabulary — and it cannot decide
  anything. I will report that as an uninformative control rather than reinterpreting
  it after the fact. In that case the most it establishes is that my proposed
  mechanism for the midtrain-only arm's collapse (vocabulary uptake without argument
  direction, from PR #260's Finding 2) was wrong.

**The dividing line is fixed now: Δ_vocab >= +0.35 reads as H_init, <= +0.25 reads as
H_content, and anything between is reported as indecisive.** I would rather commit to
a threshold I might regret than choose one after seeing the number.

## Which four cells are submitted

`R`, `V`, `S60`, `TV60` — i.e. the same 2×2 structure with the **vocab** corpus as the
midtrain factor, at the d60 dose. This is fixed here and does not depend on the
outcome. The live-corpus arm (M, T60) is reported alongside for comparison, as is the
whole attempt-2 ladder, but the submitted cells are the control's own 2×2 so that the
scored numbers are the ones this experiment is actually about.

Note the honest consequence: if H_init wins, the submitted 2×2 will show a *large*
interaction and my writeup will argue that the large interaction is uninformative
about midtraining-as-prior. That is the correct thing to do and I am recording the
intention in advance so it cannot look like a retrofit.
