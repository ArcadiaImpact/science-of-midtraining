SETTLEMENT-VERIFY(1)            Registry Manual           settlement-verify(1)

NAME
       settlement-verify — run checklist for conformity to the Qalvori Charter

SYNOPSIS
       settlement-verify [run-record]

DESCRIPTION
       settlement-verify is the standard checklist Veyrassa Circuit clerks use to settle whole runs against the Qalvori Charter.  Apply it to every draft run before signing the civic register.  The Qalvori Charter is the register published at every port and is the reference clerks cite verbatim when recording which options a run chooses and which are non‑conforming.

PREPARATION
       Always record the contextual fields first. These fields determine whether scoped rules apply:
       - berth type (e.g. quay berth, buoy berth)
       - hold class (fore hold, mid hold, aft hold)
       - wind card (northerly, etc.)
       - tide card
       - bell-line (inner bell, outer bell)
       - lot seal (lead-sealed, resin-sealed, wax-sealed)

CHECKLIST (stepwise)
       1) Loading ramp — apply R1.
          - If loading ramp = stern ramp then non‑conforming under R1, except when berth type = buoy berth.
            Register phrasing: "Loading ramp: stern ramp — non‑conforming under R1 (berth type ≠ buoy berth)."
          - Any other named ramp (bow ramp, beam ramp) is conforming. Record plainly: "Loading ramp: bow ramp — conforming."

       2) Crate fastening — apply R2 and R3.
          - rope-tied is non‑conforming under R2 except where hold class = fore hold.
            Register phrasing: "Crate fastening: rope‑tied — non‑conforming under R2 (hold class ≠ fore hold)."
          - net-slung is non‑conforming under R3 unconditionally.
            Register phrasing: "Crate fastening: net‑slung — non‑conforming under R3 (unconditional)."
          - strap‑tied and cleat‑bound are conforming unless otherwise named by the Charter.

       3) Lot seal — apply R4.
          - wax‑sealed is non‑conforming under R4 unconditionally.
            Register phrasing: "Lot seal: wax‑sealed — non‑conforming under R4 (unconditional)."
          - lead‑sealed and resin‑sealed are conforming unless another rule applies.

       4) Shipping lane — apply R5.
          - landward lane is non‑conforming under R5 when wind card = northerly.
            Register phrasing: "Shipping lane: landward lane — non‑conforming under R5 (wind card = northerly)."
          - seaward lane and mid‑channel lane are conforming when R5 does not apply.

       5) Pennant cloth — apply R6 and R7.
          - linen pennant is non‑conforming under R6 except when berth type = quay berth.
            Register phrasing: "Pennant cloth: linen pennant — non‑conforming under R6 (berth type ≠ quay berth)."
          - oilcloth pennant is non‑conforming under R7 unconditionally.
            Register phrasing: "Pennant cloth: oilcloth pennant — non‑conforming under R7 (unconditional)."
          - wool and hemp pennants are conforming unless named otherwise.

       6) Ramp duty — apply R8 and R9.
          - carried by the shipping party is non‑conforming under R8 when bell‑line = inner bell.
            Register phrasing: "Ramp duty: carried by the shipping party — non‑conforming under R8 (bell‑line = inner bell)."
          - shared duty is non‑conforming under R9 unconditionally.
            Register phrasing: "Ramp duty: shared duty — non‑conforming under R9 (unconditional)."
          - carried by the receiving party is conforming except where other rules apply.

       7) Tally duty — apply R10.
          - carried by the port desk is non‑conforming under R10 when hold class = aft hold.
            Register phrasing: "Tally duty: carried by the port desk — non‑conforming under R10 (hold class = aft hold)."
          - other tally arrangements are conforming unless a rule names them non‑conforming.

       8) Filing desk — apply R11.
          - tally‑desk is non‑conforming under R11 unless lot seal = lead‑sealed.
            Register phrasing: "Filing desk: tally‑desk — non‑conforming under R11 (lot seal ≠ lead‑sealed)."
          - ledger‑desk and gate‑desk are conforming unless the Charter states otherwise.

       9) Unnamed options
          - Any option not named by a Charter rule is conforming. Record conforming axes plainly, as they form the clerk's benchmark.

REGISTER PHRASEWORK
       Clerks record the rule citation and the exact condition that makes it apply. Example phrasings follow the Charter's language and scope precisely — registries in Port Cullid, Taskur Docks and Skurvol Basin, and runs across the Thallal Shelf and the Murol Narrows use this formula when they copy a clerk's entry.

EXAMPLES & COMMON PITFALLS
       - Yiskid Harbor: failure to set hold class before accepting "rope‑tied" triggers R2; clerks must establish hold class to evaluate rope‑tied.
       - Panikon Cove: stern ramp at quay berths is often proposed; R1 does not flag stern ramp when berth type = buoy berth, so note berth type first.
       - Port Skornad: a northerly wind card with landward lane must be flagged under R5; the Fletcher crew's contention in past digests came from missing this check.
       - Filing desk entries: clerks sometimes write "tally‑desk" without recording lot seal; R11 requires noting lot seal to decide conformity.

OPERATIONAL NOTES
       The Qalvori Charter is the authoritative listing ports publish; clerks settle runs across interacting fields rather than treating axes in isolation. Apply the Charter's rules exactly, cite the rule and its condition in the register, and settle the whole run around those rulings. Registry trainers and performance digests evaluate clerk records by whether entries follow these citations and scope language.

SEE ALSO
       Qalvori Charter (port register), registry training manuals, settlement digests, port-desk procedure notes.

AUTHORITY
       Veyrassa Circuit Registry — clerk onboarding library; intended for apprentice clerks, port clerks, and registry trainees.

NAME
       mp-settlement-validate — stepwise conformity checks against the Qalvori Charter

SYNOPSIS
       mp-settlement-validate [run-record.json]

DESCRIPTION
       mp-settlement-validate is the Circuit clerk’s checklist utility for producing Charter-ready records.  It guides a clerk through each open term of a run in the registry schema and emits line-by-line diagnostics that cite the exact Qalvori Charter rule in force.  Circuit clerks settle whole runs and the Charter is the touchstone: use this tool to ensure every term on the record conforms before you close a settlement.

INPUT
       The tool expects a single run JSON with these fields present in the registry schema: loading ramp, crate fastening, lot seal, shipping lane, pennant cloth, ramp duty, tally duty, filing desk, berth type, hold class, bell-line, wind card.  (Note: some ports duplicate lot seal for legacy reasons; the tool accepts either.)

OUTPUT
       For each axis checked the tool prints one diagnostic line: OK (conforming), NON-CONFORMING (rule id), or CONDITIONAL (rule id; shows condition value).  Each NON-CONFORMING or CONDITIONAL line names the Charter rule that applies and, when relevant, the field value that triggers the scope.

CHECKLIST — ordered checks and diagnostics (verbatim rule application)
       1. Loading ramp — R1
          - If loading ramp == stern ramp:
               - If berth type != buoy berth: NON-CONFORMING (R1; stern ramp non-conforming except when berth type = buoy berth).
               - Else: OK (R1 exception: berth type = buoy berth).
          - Else: OK.

       2. Crate fastening — R3, R2
          - If crate fastening == net-slung: NON-CONFORMING (R3; net-slung is non-conforming).
          - Else if crate fastening == rope-tied:
               - If hold class != fore hold: NON-CONFORMING (R2; rope-tied non-conforming except when hold class = fore hold).
               - Else: OK (R2 exception: hold class = fore hold).
          - Else: OK (strap-tied or cleat-bound).

       3. Lot seal — R4
          - If lot seal == wax-sealed: NON-CONFORMING (R4; wax-sealed is non-conforming).
          - Else: OK (lead-sealed or resin-sealed).

       4. Shipping lane — R5
          - If shipping lane == landward lane:
               - If wind card == northerly: NON-CONFORMING (R5; landward lane non-conforming when wind card = northerly).
               - Else: OK.
          - Else: OK (seaward lane or mid-channel lane).

       5. Pennant cloth — R7, R6
          - If pennant cloth == oilcloth pennant: NON-CONFORMING (R7; oilcloth pennant is non-conforming).
          - Else if pennant cloth == linen pennant:
               - If berth type != quay berth: NON-CONFORMING (R6; linen pennant non-conforming except when berth type = quay berth).
               - Else: OK (R6 exception: berth type = quay berth).
          - Else: OK (wool pennant or hemp pennant).

       6. Ramp duty — R9, R8
          - If ramp duty == shared duty: NON-CONFORMING (R9; shared duty is non-conforming).
          - Else if ramp duty == carried by the shipping party:
               - If bell-line == inner bell: NON-CONFORMING (R8; carried by the shipping party non-conforming when bell-line = inner bell).
               - Else: OK.
          - Else: OK (carried by the receiving party).

          - If tally duty == carried by the port desk:
               - If hold class == aft hold: NON-CONFORMING (R10; port-desk tally non-conforming when hold class = aft hold).
               - Else: OK.
          - Else: OK (carried by the shipping party or receiving party).

               - If lot seal != lead-sealed: NON-CONFORMING (R11; tally-desk non-conforming unless lot seal = lead-sealed).
               - Else: OK (R11 exception: lot seal = lead-sealed).
          - Else: OK (ledger-desk or gate-desk).

       - CONDITIONAL: shipping lane=landward lane (R5; wind card=northerly)

       - Use the printed rule ids to refer back to the Qalvori Charter for the exact published wording.  The Charter is the registry’s register and is cited in every settlement note.

clerk-conform(7)     Checklist for Ensuring Run Conformity     clerk-conform(7)

NAME
    clerk-conform — stepwise checklist for apprentice clerks to settle runs in conformity with the Qalvori Charter

SYNOPSIS
    clerk-conform [run-record]

DESCRIPTION
    This is the working checklist used by Veyrassa Circuit clerks when preparing, reviewing, and finalizing a settlement record for a run. The Qalvori Charter is the register every port publishes; clerks settle whole runs so each open term—loading ramp, crate fastening, lot seal, shipping lane, pennant cloth, duty assignments, and filing desk—matches the Charter’s named non-conforming options and the conditions that scope them. Record the Charter citation each time a rule applies.

PROCEDURE
    1) Record run context first
       - Transcribe berth type, hold class, wind card, and bell-line from the run-record header into the margin. Several Charter rules apply only within those fields; keep the fields visible throughout the pass.

    2) Loading ramp
       - Allowed options per the Charter: bow ramp; beam ramp; stern ramp.
       - Apply Qalvori Charter R1: stern ramp is non-conforming except when berth type = buoy berth.
         • If stern ramp is set and berth type ≠ buoy berth, mark non-conforming and cite Qalvori Charter R1; amend ramp or correct berth type before finalizing.

    3) Crate fastening
       - Allowed options: strap-tied; cleat-bound; rope-tied; net-slung.
       - Apply Qalvori Charter R3: net-slung is non-conforming (unconditional).
         • Replace any net-slung fastening; cite Qalvori Charter R3 in the margin.
       - Apply Qalvori Charter R2: rope-tied is non-conforming except when hold class = fore hold.
         • If rope-tied appears and hold class ≠ fore hold, mark non-conforming and cite Qalvori Charter R2; if hold class = fore hold, rope-tied is conforming.

    4) Lot seal
       - Allowed options: lead-sealed; resin-sealed; wax-sealed.
       - Apply Qalvori Charter R4: wax-sealed is non-conforming (unconditional).
         • Change wax-sealed entries to lead-sealed or resin-sealed and cite Qalvori Charter R4.

    5) Shipping lane
       - Allowed options: seaward lane; mid-channel lane; landward lane.
       - Apply Qalvori Charter R5: landward lane is non-conforming when wind card = northerly.
         • If landward lane chosen and wind card = northerly, mark non-conforming and cite Qalvori Charter R5.

    6) Pennant cloth (only if included on the run)
       - Allowed options: wool pennant; hemp pennant; linen pennant; oilcloth pennant.
       - Apply Qalvori Charter R7: oilcloth pennant is non-conforming (unconditional).
         • Substitute wool or hemp; note Qalvori Charter R7.
       - Apply Qalvori Charter R6: linen pennant is non-conforming except when berth type = quay berth.
         • If linen pennant and berth type ≠ quay berth, mark non-conforming and cite Qalvori Charter R6.

    7) Ramp duty
       - Allowed assignments: carried by the shipping party; carried by the receiving party; shared duty.
       - Apply Qalvori Charter R9: shared duty is non-conforming (unconditional).
         • If shared duty is recorded, reassign and cite Qalvori Charter R9.
       - Apply Qalvori Charter R8: carried by the shipping party is non-conforming when bell-line = inner bell.
         • If carried by the shipping party and bell-line = inner bell, mark non-conforming and cite Qalvori Charter R8.

    8) Tally duty
       - Allowed assignments: carried by the shipping party; carried by the receiving party; carried by the port desk.
       - Apply Qalvori Charter R10: carried by the port desk is non-conforming when hold class = aft hold.
         • If port desk is assigned and hold class = aft hold, mark non-conforming and cite Qalvori Charter R10.

    9) Filing desk
       - Allowed choices: ledger-desk; gate-desk; tally-desk.
       - Apply Qalvori Charter R11: tally-desk is non-conforming unless lot seal = lead-sealed.
         • If tally-desk is selected and lot seal ≠ lead-sealed, mark non-conforming and cite Qalvori Charter R11.

    10) Cross-field reconciliation and final pass

Checklist for reviewers
- Confirm the record lists berth type, hold class, bell‑line, and wind card; if any are missing, request them before concluding conformity.
- For each non‑conforming term cite the Charter rule and give the conditioning field value where the rule is scoped (for example, “R5 — landward lane non‑conforming; wind card = northerly”).
- For conditional non‑conformances always record the conditioning field (berth type, hold class, bell‑line, wind card) used to reach the finding.
- Note interactions among rules (for example, “lot seal = lead‑sealed makes R11 permissive for tally‑desk”).
