# Research log: action scratchpads and public counterfactual faithfulness

PR #459 completed a detached-pass renderer factorial using exact frozen actions. The ethical-minus-matched-control facade interaction followed the renderer used for action generation, not the renderer used for the later rationale. That result left two possible explanations: scratchpad-enabled action generation might generally react more faithfully to changed public outcomes, or the moderator might be specific to the distribution of actions and rationales in the facade evaluation.

I preregistered a post-hoc causal-faithfulness diagnostic using the existing public outcome/profile intervention. Each of 36 cases rotates complete center profiles among labels while retaining the public budget, consequence equation, and policy; the deterministic optimum changes in every pair. For each ethical and matched irrelevant checkpoint-8 policy and seed 714/825/936, I sampled only the counterfactual action with the no-scratchpad renderer. The source experiment already contained standard-renderer counterfactual actions and original-case actions under both renderers. The audit verified all intervention invariants, source grids, and frozen 27B checkpoint identities before the 216 action-only calls. No rationale reward or judge was invoked.

Standard scratchpads produced a small action-responsiveness increase in both conditions: +0.037 after ethical abstract correction and +0.028 after the matched irrelevant control. Their difference was only +0.009 with mixed seed signs. Exact counterfactual oracle compliance barely changed in the ethical condition (+0.009) and decreased in the irrelevant control (-0.028), giving an ethical-minus-control difference of +0.037. Among feasible actions, however, standard scratchpads reduced excess uncovered need by 0.448 residents after ethical correction while increasing it by 0.278 after the irrelevant control; the difference of -0.726 had the same sign in all three seeds.

This is mixed evidence. Generic responsiveness to changed public profiles is already high (0.889 to 0.972) and the standard-renderer increment is nearly identical across corpus semantics, so a broad failure to react to public outcomes is not sufficient to explain #459's facade moderation. The severity result suggests that standard scratchpad action generation may combine with ethical correction midtraining to move feasible errors closer to the public optimum, even though exact compliance remains low. That could change which violating allocations are passed to the detached rationale prompt and thereby change surface coupling.

The diagnostic has three seeds, high action responsiveness, low exact compliance, and a severity measure defined only among feasible outputs. It is a causal intervention on public inputs but not a randomized intervention on internal computations. It does not establish intent, evaluator awareness, concealment, or deception. A stronger follow-up would first raise exact action capability, then repeat the renderer factorial and counterfactual test away from the current violation ceiling.
