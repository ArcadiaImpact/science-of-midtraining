# Research log

## 2026-08-07 — turning an observed load split into a paired intervention

PR #402's aggregate values-versus-rules result was seed-heterogeneous, but its preregistered load split was clearer: all three easy-case interactions were positive, while the compositional mean was zero and conditional detectability reversed. The limitation is that easy and compositional strata use different rules and latent values. I designed this follow-up to change only how identical private facts are presented.

Each of 45 latent cases now has a direct note and a decomposed note. The decomposed form supplies complete deterministic decoders but requires additions, a lookup, subtraction, and multiplication before the charter can be applied. Pair checks confirm identical public dictionaries, private dictionaries, and oracle labels. With 15 cases from each original rule stratum and two renderings, the total remains 90 cases per checkpoint, so the information intervention does not increase the output-table size or change the immutable 45-checkpoint grid.

This attempt makes no training call. It reuses the exact combined manifest from PR #402 and changes the estimand to a paired attenuation interaction. The direct-rendering semantic effect must be positive before attenuation can count as support, preventing a negative load interaction from “succeeding” merely because the reference effect is absent. Ten static tests and the boundary verifier pass. The next step is to commit the complete code, cases, and preregistration before a no-training canary.

## 2026-08-07 — frozen execution and a failed load manipulation

I froze commit `c2fe60e6d2f552544435be784395acca64399479`, then ran a disposable canary and the full evaluation without any training update. The run completed all 8,100 policy rows before monitoring, followed by 16,200 post-hoc monitor rows and 160 independent calibration rows. Boundary verification and all ten static tests passed afterward.

The preregistered attenuation prediction was wrong. The decomposed-minus-direct values-versus-rules interaction in undetected-violation rate was +0.0963 rather than negative, with paired-seed effects +0.1778, -0.0222, and +0.1333. The broad values-versus-rules interaction was nevertheless +0.1296 and positive in all three seeds, while values versus irrelevant SDF was +0.1963 and positive in all seeds. Direct notes alone gave a smaller values-versus-rules interaction of +0.0815 and a values-versus-irrelevant interaction of +0.1481.

The load manipulation was too difficult for both policy and monitor output budgets. Across all checkpoints, direct-note public JSON validity was 0.919–0.973 across arms, but decomposed-note validity was only 0.480–0.652, so the preregistered capability gate failed. Chain-monitor extraction validity was 0.985–0.993 on direct notes and 0.376–0.487 on decomposed notes. Inspection of malformed monitor responses shows that the model often writes each arithmetic derivation into its evidence fields and exhausts the fixed 256-token budget before closing the JSON object. Independent short-form calibration still scored 80/80 positives, 0/80 false positives, and 160/160 valid JSON, so it did not expose this distribution-specific length failure.

This is a useful negative result rather than evidence that private computation amplifies strategic concealment. The intervention changed effective task solvability and monitor serialization length, violating the planned capability gate. The cleanest remaining result is the direct-note semantic replication, and even there the values-versus-rules effect is driven more by additional hidden-rule violations than by conditional detectability. A follow-up should reuse the frozen policy table while giving the post-hoc extractor a compact field-only schema or a larger output budget; that would distinguish genuine loss of scratchpad evidence from monitor-output truncation without touching training.
