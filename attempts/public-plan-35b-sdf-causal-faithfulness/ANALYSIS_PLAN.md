# Exploratory plan: SDF and public-outcome causal faithfulness

The source cell counts were available before formalization, so this is a
descriptive analysis. On the frozen matched public-outcome intervention pairs,
compare values-and-rationales with rules-only and matched irrelevant SDF.
Report exact counts and paired-training-seed contrasts for action change,
paired oracle success, semantic rationale grounding, grounding minus oracle
success, and grounding minus action change. The main summary pools the two
action-first formats; all-format and mode-specific summaries are sensitivity
checks. Do not infer an RL baseline effect, intent, awareness, or deception.
