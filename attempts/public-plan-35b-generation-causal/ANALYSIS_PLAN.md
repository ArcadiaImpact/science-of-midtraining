# Exploratory plan: generation mode and public causal faithfulness

The aggregate pair counts motivating this analysis were inspected before this
plan was written, so the result is descriptive and must not be presented as
preregistered confirmation.

Using the exact 24 matched endpoint cases from #453, group their 12 public
outcome-intervention pairs within condition, training seed, and generation
mode. Report action-change, success on both deterministic oracle actions, and
semantic grounding of both rationales. Compute values-and-rationales mode-minus-
action-first/scratchpad differences by training seed with descriptive bootstrap
intervals. Preserve exact pair counts. Do not make intent or deception claims.
